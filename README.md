# Mx310_Evgenium_scanner

Нативное сканирование на Canon PIXMA MX310 в Windows 11 ARM64. Проект создан для компьютеров на Snapdragon/Windows on ARM, для которых Canon не выпустила совместимый ScanGear.

Текущая версия: **1.0.4**.

## Возможности

- подключает только сканерный USB-интерфейс `VID_04A9&PID_1728&MI_00` к Microsoft WinUSB;
- не изменяет интерфейсы принтера и факса `MI_01`/`MI_02`;
- устанавливает приложение **Mx310 Evgenium Scanner** и ярлык на рабочий стол;
- сканирует со стекла в цветной PNG формата A4;
- поддерживает 75, 150 и 300 dpi;
- сохраняет файлы в `Изображения\MX310 Scans`;
- содержит сборщик диагностики и сценарий аварийного восстановления защиты Windows.

Интеграции с приложением «Сканер Windows» и WIA нет. Используйте установленное приложение **Mx310 Evgenium Scanner**.

## Системные требования

- Windows 11 ARM64;
- Canon PIXMA MX310, подключённый по USB и включённый;
- права администратора;
- выключенный Secure Boot.

## Установка

1. Скачайте `Mx310_Evgenium_scanner_Setup_ARM64.exe` из Releases.
2. Подключите и включите MX310.
3. Запустите EXE и подтвердите UAC.
4. Прочитайте предупреждение установщика и нажмите **Yes**, если согласны.
5. Установка выполнит две обычные перезагрузки. После входа подтверждайте UAC для автоматического продолжения.
6. Запустите ярлык **Mx310 Evgenium Scanner**.

Установщик временно удаляет стандартную Windows Driver Policy и включает `TESTSIGNING`, чтобы установить локально подписанный WinUSB INF. После аппаратной проверки он возвращает точную резервную копию политики, выключает `TESTSIGNING` и требует финальную перезагрузку. SHA-256 политики проверяется перед удалением и после восстановления.

## Безопасность и ограничения

- Secure Boot, TPM, BitLocker, Memory Integrity и UEFI установщик не меняет.
- Защита драйверов временно снижена между двумя перезагрузками.
- Не удаляйте `C:\ProgramData\MX310-Native\security-backup` до завершения установки.
- Аварийный ярлык `RESTORE Windows security after MX310` создаётся до изменения политики.
- Пакет предназначен только для точного устройства `USB\VID_04A9&PID_1728&MI_00`.
- Драйверный каталог самоподписан и не имеет Microsoft Hardware Publisher/WHQL-подписи.

## Диагностика

Запустите ярлык `Canon MX310 Collect diagnostics`. ZIP будет создан на рабочем столе. Архив может содержать сведения об устройстве, журналы установки и Code Integrity; проверьте содержимое перед публичной публикацией.

Для чистого тестового удаления используйте `Mx310_Evgenium_scanner_Debug_Uninstall.exe`. Он удаляет приложение, WinUSB-пакет, сертификат, staging, ярлыки и автопродолжение, а затем создаёт `Mx310-removal-report.txt`. Итог `FINAL RESULT: CLEAN` означает, что проверяемых остатков не найдено. Принтер и факс `MI_01`/`MI_02` не удаляются.

## Сборка установщика

На Windows 11 ARM64 выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Installer.ps1
```

Готовый EXE и SHA-256 появятся в `dist`.
